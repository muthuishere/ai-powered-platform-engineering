# Chapter Diagrams

Hand-drawn (Excalidraw, Virgil sketch font) monochrome diagrams. Deliberately
**minimal** — at most ~3–4 boxes each, one idea per figure. A diagram is kept
only where a picture beats prose (a *flow*, a *boundary*, or *containment*);
everywhere else the book uses a table or a sentence instead.

Source `.excalidraw` lives beside the rendered `.png`/`.svg` so they stay editable.
Rendered via the `hand-drawn-diagrams` skill (`exportToSvg` → PNG).

| File | Chapter | The one idea |
|------|---------|--------------|
| `ch2-guardrails.*` | 2 — Safe scaffold | Reads pass the guard wall; writes hit it and are blocked |
| `ch4-maturity-report.*` | 4 — Security/Certs/Report | Five read-only checks collapse into one graded A–F score |
| `ch5-gitops-remediation.*` | 5 — GitOps Remediation | The agent proposes a PR; it never crosses the audit boundary onto the cluster |
| `ch9-sovereign-operator.*` | 9 — Sovereign AI Operator | One sealed on-prem image; nothing leaves the building |
